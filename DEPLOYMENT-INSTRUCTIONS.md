## ✅ STEP-BY-STEP DEPLOYMENT (10 MINUTES)

### Step 1: Create New Repository on GitHub

1. **Go to GitHub**: https://github.com/new
2. **Fill in:**
   - Repository name: `HCMS` (EXACTLY as shown - all caps)
   - Description: "Henry Coaster Memorial School Website"
   - **Public** (must be public for GitHub Pages)
   - **DO NOT** check "Add a README file"
   - **DO NOT** check "Add .gitignore"
   - **DO NOT** choose a license
3. **Click**: "Create repository"

### Step 2: Upload Your Website Files

1. **You'll see a page with instructions** - ignore them
2. **Look for the text**: "uploading an existing file" - **CLICK IT**
3. **On your computer**: 
   - Open the downloaded ZIP file
   - Extract it
   - Open the `hcms-fresh` folder
   - **Select ALL files and folders inside** (use Ctrl+A or Cmd+A)
4. **Drag all selected files** to the GitHub upload page
5. **Wait for upload** (may take 30-60 seconds)
6. **Scroll down**, write: "Initial website deployment"
7. **Click**: "Commit changes" (green button)

### Step 3: Enable GitHub Pages

1. **Click**: "Settings" tab (top of repository page)
2. **In left sidebar**: Scroll down and click "Pages"
3. **Under "Source"**:
   - Branch: Select **"main"** (or "master" if that's what shows)
   - Folder: Select **"/ (root)"**
4. **Click**: "Save"
5. **You'll see**: "Your site is ready to be published at https://reckegabe58.github.io/HCMS/"

### Step 4: Wait for Build (2-3 minutes)

1. **Click**: "Actions" tab (top of repository)
2. **You'll see**: A yellow dot (building) or green checkmark (done)
3. **Wait** for the green checkmark ✅
4. **If you see a red X** ❌: 
   - Click on it
   - Screenshot the error
   - Send it to me

### Step 5: Visit Your Live Site!

1. **Go to**: https://reckegabe58.github.io/HCMS/
2. **Do a hard refresh**:
   - **Windows**: Ctrl + Shift + R
   - **Mac**: Cmd + Shift + R

## 📋 TROUBLESHOOTING

### "My site shows 404 Not Found"
- Wait 3-5 minutes - GitHub takes time to build
- Make sure repository is **Public** (not Private)
- Check Settings → Pages shows "Your site is published"

### "CSS isn't loading / Looks plain"
- You didn't follow step 3 correctly - the branch or folder is wrong
- Go back to Settings → Pages
- Make sure: Branch = "main", Folder = "/ (root)"
- Save and wait 2 minutes

### "Images aren't showing"
- This is normal - the carousel has placeholder images
- Replace them with your real photos (see "What To Do Next" above)

### "Actions tab shows red X"
- Click on the failed action
- Screenshot the error
- Send it to me - I'll fix it
